# N1 – Aquisição e Preparação de Dados: Pix x TED

Comparação da evolução do Pix e da TED com dados abertos do Banco Central do Brasil (API Olinda).

## Conteúdo
- `N1_Pix_TED.ipynb`: notebook (Google Colab, Python/pandas, sem planilhas) com aquisição, classificação, tratamento, integração e gráfico.
- `tabela_final_pix_ted.csv`: tabela final integrada (1 linha por mês).
- `grafico_pix_ted.png`: gráfico de comparação.

## Fontes
- BCB – Portal de Dados Abertos: Pix (`Pix_DadosAbertos`) e Estatísticas de Meios de Pagamentos (`MPV_DadosAbertos`).

## Como rodar
Abra o notebook no Google Colab e execute tudo. Os dados são baixados por código.
